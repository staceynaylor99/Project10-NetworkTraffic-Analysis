# Project 10 – Network Traffic Analysis (Wireshark)

## Overview
In this project, I used Wireshark to capture and study real network traffic from my Windows virtual machine. I created ICMP, DNS, HTTP, and TLS traffic and learned how each protocol looks inside a packet capture.

---

## What I Did
- Captured live traffic in Wireshark  
- Used filters to isolate ICMP, DNS, HTTP, and TLS  
- Triggered traffic using simple commands (ping, nslookup, curl)  
- Saved screenshots and a .pcapng file for evidence  
- Wrote a summary explaining what each protocol shows

---

## Key Takeaways
- **ICMP** shows repeating ping traffic (beaconing pattern)  
- **DNS** shows domain lookups and responses  
- **HTTP** shows readable web requests and responses  
- **TLS** shows encrypted communication and handshake steps  

---

## Files Included
- **NetworkTrafficAnalysis.md** – My notes

This project helped me learn how network traffic looks at the packet level and how SOC analysts identify patterns during investigations.
